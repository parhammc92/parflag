# 🚩 پرچم — تمرین کدنویسی مبتدی + بات تعیین سطح

پروژه‌ی مدرسه: سایتی برای یادگیری برنامه‌نویسی از صفر، به فارسی و راست‌به‌چپ.

## امکانات

### تمرین‌ها (بدون نیاز به سرور)
- ۲۰ تمرین مبتدی در ۴ زبان: **Python، JavaScript، C++، Java**
- اجرای زنده: JavaScript در مرورگر، Python با موتور [Pyodide](https://pyodide.org)
- C++ و Java در «حالت یادگیری»: کد بنویس و با راه‌حل مقایسه کن
- راهنما و راه‌حل برای هر تمرین، نوار پیشرفت و ذخیره‌ی خودکار کدها

### 🤖 بات تعیین سطح (نیاز به سرور)
- آزمون **۸ سؤالی تطبیقی**: دو جواب درست پشت‌سرهم → سؤال سخت‌تر، دو اشتباه → آسون‌تر
- تصحیح **سمت سرور** (جواب‌ها هرگز به مرورگر فرستاده نمی‌شوند)
- نتیجه: 🥉 مبتدی / 🥈 متوسط / 🥇 پیشرفته + تمرین پیشنهادی
- ذخیره‌ی نتایج در SQLite و نمایش سابقه

## اجرا

```bash
# نصب وابستگی‌ها (فقط Flask)
pip install -r requirements.txt

# اجرای سرور
python server.py
```

| آدرس | صفحه |
|---|---|
| http://localhost:5001/ | تمرین‌ها |
| http://localhost:5001/quiz | بات تعیین سطح |

> تمرین‌ها حتی بدون سرور هم کار می‌کنند — کافیست `index.html` را دابل‌کلیک کنید.
> (برای اجرای Python به اینترنت نیاز است، فقط بار اول)

## ساختار

```
├── index.html / index.css / app.js     ← سایت تمرین (فرانت‌اند)
├── quiz.html / quiz.css / quiz.js      ← بات تعیین سطح (فرانت‌اند)
├── server.py                            ← بک‌اند Flask (سرو سایت + API آزمون)
├── questions.py                         ← بانک سؤالات (۷۲ سؤال، ۴ زبان × ۳ سطح)
├── quizdb.py                            ← لایه‌ی دیتابیس SQLite
└── requirements.txt
```

## API

| مسیر | متد | کار |
|---|---|---|
| `/api/health` | GET | سلامت سرور + تعداد سؤال‌ها |
| `/api/quiz/start` | POST | شروع آزمون → سؤال اول (بدون جواب) |
| `/api/quiz/answer` | POST | جواب → تصحیح + سؤال بعدی (تطبیقی) |
| `/api/quiz/finish` | POST | رها کردن آزمون |
| `/api/quiz/history` | GET | ۱۰ نتیجه‌ی آخر |

## پایداری

- همه‌ی خطاهای API با JSON پاسخ داده می‌شوند (۴۰۰/۴۰۴/۴۰۵/۵۰۰)
- اعتبارسنجی ورودی‌ها: زبان معتبر، اندیس گزینه، سقف حجم بدنه (۴KB)
- جلوگیری از path traversal در سرو فایل‌های استاتیک
- فایل‌های بک‌اند (`.py`, `.db`) از وب سرو نمی‌شوند
- کلاینت: بنر راهنما اگر سرور خاموش باشد، ذخیره‌ی پیشرفت در localStorage
